# 四个大盘 · R10 设计原型(运维日报)

2026-10-15 定稿保存。这是**设计原型**,不是产品代码;产品前端仍是 `frontend/`。
编辑式设计 / 数据新闻:FT、《经济学人》图表版、纽约时报头版一路,把四个大盘排成一份报纸。

- **头版**:报头(日期、期数、实例版)、头条(健康检查:大标题、导语、署名、带注释的走势图、两栏正文与首字下沉)、
  右栏「本期数字」与「八项检查一览」;折线以下三个小栏目(负载、慢语句、知识),各自「详见 X 版」。
- **内页**:A2 要闻·健康检查(全部发现、八个维度小格、编者按、往期巡检)、B1 慢语句(份额条、调优札记、完整榜单)、
  C1 负载(八项指标前后对照、DB Time、等待构成、窗口 Top SQL)、D1 知识(案例摘编、缺口、检索、条款)。
- 视觉:米色新闻纸、墨色细线分栏;宋体(macOS 自带「宋体-简」,Windows 回落到中易宋体)标题与正文、Georgia 数字;全页只有一个强调红,给「最该看的那一处」。
  图表都是墨线:变坏的用红,变好的用绿,其余墨色;状态仍配图标与文字。
- 路由只决定翻到哪一版;点表格行、案例标题、⌘K 检索都照常打开详情。

数据与文字生成沿用 R6,版式在 `js/paper.js`、`js/sections.js`,图表在 `js/press.js`,样式在 `r10.css`。
打开(在 `docs/prototypes` 下起 `python3 -m http.server 18300 --bind 127.0.0.1`):`http://127.0.0.1:18300/dash-r10/index.html#/health`

## 数据与字体

本目录自带数据、字体与脚本,可单独打开。`data.js` 与 R5/R6 相同,由 `build-data.py` 从 `scripts/dash-samples.py` 生成的样例报告打包;
标「示意」或画成空心的条目是原型补充。字体在 `fonts/`(IBM Plex,SIL Open Font License,见 `fonts/LICENSE.txt`)。
截图验收参数同 R6:`?still` 跳过动效,`?inst=` `?dim=` `?sql=` `?case=` `?wdim=` `?cmdk=` `?ask=`。
