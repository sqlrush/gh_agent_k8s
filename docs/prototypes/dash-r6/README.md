# 四个大盘 · R6 设计原型(智能运维舱)

2026-10-15 定稿保存。在 R5(云控制台,存于 `dash-r5/`)的骨架、字体与口径上,引入 2025–2026 的设计语言。
这是**设计原型**,不是产品代码;产品前端仍是 `frontend/`。本目录自带数据、字体与脚本,可单独打开。

## 怎么打开

```bash
cd docs/prototypes
python3 -m http.server 18300 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:18300/dash-r6/index.html#/health
```

`⌘K` 命令面板(搜页面、实例、SQL、维度、案例,或直接提问);`⌘J` 智能体侧栏。顶部「实例」切到 og-std 可看采集失败。

## 相对 R5 新增了什么

- **主视觉带**:每页顶部一条深蓝极光带,全页只在这一处用力;其下仍是 R5 的白、克制。玻璃材质只用在这条带的卡片和浮层上。
- **智能体解读是页面的一等内容**:结论、要点(带可点的证据小签)、建议追问、提问框。文字由报告**确定性生成**,不另编数,
  卡片右上角标明依据哪份报告、级别由脚本判定。
- **每页一个主图**:健康检查 = 检查项圆环(异常段着色、正常段素色、采集失败为细虚线);Top SQL = 耗时树图(面积 = 占比,
  斜纹为系统 SQL);WDR = 八个指标的对比哑铃(比例尺从 0 开始,不放大差异);知识库 = 条目数、覆盖环与关系缩略图。
- **便当盒布局**:大小不一的卡片、大圆角、宽间距;巡检节奏把发现条数曲线和每次的级别格按同一横轴对齐。
- **⌘K 命令面板、⌘J 上下文侧栏**:侧栏带上当前页面的上下文(实例、报告时间、发现数)。原型不连 opencode,提问后只说明真实环境会怎样回答。
- **一次编排好的入场**:卡片错开浮现、圆环描边、数字滚动;只在进入页面或切实例时播放,`prefers-reduced-motion` 时直接是终态。

## 配色校验

图表色经 dataviz 校验脚本检查:树图只用「业务一个蓝 + 系统斜纹灰」,关系缩略图节点单色(类别由列位置与列名表达),
不再用多色类别板;状态色沿用 R5,始终配图标与文字。

## 截图验收参数

`?still` 跳过动效直接画终态;`?inst=` `?by=` `?tab=`;`?dim=` `?xdim=` `?wdim=` `?sql=` `?case=` 打开对应抽屉;
`?cmdk=<关键词>` 打开命令面板;`?assist=1` / `?ask=<问题>` 打开智能体侧栏。

代码按职责拆成 `js/` 下七个文件:`core`(数据、级别、格式化、部件)、`viz`(图形)、四个页面、`shell`(路由、浮层、事件)。

## 数据

`data.js` 与 R5 相同,由 `build-data.py` 从 `scripts/dash-samples.py` 生成的样例报告打包;巡检历史与窗口历史里 `demo: true` 的条目是示意,画成空心、点不开。
字体在 `fonts/`,SIL Open Font License(见 `fonts/LICENSE.txt`)。

## 换风格

主视觉带里图形的配色都是 `app.css` 顶部的变量(`--tm-biz`、`--db-*`、`--sb-*`、`--cov-*` 等),换风格只需覆盖变量与组件样式,脚本不用动。
