设计说明（给确认用，实现时不出现）

  • 三类知识 = 我们知识库的真实三层：案例（cases）/ 条款（rules）/ 关系图（graph）。dsh-k8s 那边是记忆 / 向量 / 图，语义不同，这里按我们的模型重排，不硬套。
  • 数据来源：gaussdb-kb health 已经打印了这页几乎全部内容（模式 / 只读 / 收件目录 / 上次索引 / 待处理 / 缺口清单）——但它现在是文本，没有 --json。要做这页，先给 health 加 JSON 输出（小改，纯技能侧）。
  • 「最近检索」需要记检索日志：现在 kb query 不落日志。要这张表就得让 query 追加一行到本人 NAS 目录（含命中数与命中方式）。要不要这张表——你拍板。
  • 「怎么命中的」区分语义 / 关键词，是因为文件模式下只有关键词；用户应该知道自己看到的是哪一种。
  • 全体共享的知识库只有一份，所以这页所有人看到的一样；只有「最近检索」是本人的。
