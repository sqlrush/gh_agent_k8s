# 发版台 · R1 设计原型(部署与发布)

2026-11-03 定稿保存。这是**设计原型**,不是产品代码;产品代码在 `release/`(分支 `feat/release-console`)。
单个 HTML 文件、原生 JS、不依赖网络,双击即可打开。所有数字、地址、脚本清单都是示例,演示中的命令一条都不会真的执行。

## 页面

- **总览**:当前版本、池子在用数、资源状态(与发布前扫描同一套检查)、实时集群架构。
- **发布**:
  - 发布前资源扫描:发布包目录、内网镜像仓库、Kubernetes、NAS、模型、中间件、白名单核对数据源、统一认证、集群余量逐项检查,
    全部可用才允许「开始发布」;不可用的写明原因与修复提示,并链到资源配置。
  - 发布流程(地铁线):12 步分「准备 / 确认 / 替换 / 验证」四段,每步显示状态、用时、子步骤进度;
    下方提示框指向当前步,给出这一步此刻能做的操作。
  - 集群架构大盘:网关两个副本,池子 3 Pod × (3 槽位 + 管家);新版本绿边,在用 / 转保留 / 换镜像 / 核验各有样式。
  - 实时日志。
- **步骤明细**(点流程图任一步进入):面包屑与 12 步小导航、页头(状态、开始、用时、执行方式、尝试次数、操作)、
  左侧子步骤时间线、右侧本步专属面板、底部「执行的命令」与「本步日志」。各步的专属面板:
  - 读包与校验:文件 sha256 表、release.yaml 摘要
  - 生成升级计划:当前版本识别(从哪里读到的)、每一步为什么做
  - 镜像入库:推送进度、层(推送 / 复用)、digest 核对
  - 配置迁移:配置差异、必填项检查、渲染出的清单
  - 变更预览:kubectl diff,确认后才改动集群
  - 白名单核对:应有 / 已登记一致 / 未登记 / 内容不一致四个数,逐条表(有问题的排前面)
  - 网关滚动更新:副本表、滚动方式
  - 池子在线替换:Pod × 槽位矩阵、每个槽位的替换链
  - 导入环境、知识库标准包(Job 容器、文档集版本对照)
  - 冒烟验证:模拟登录、一次真实对话、只读诊断报告、知识库检索
  - 完成:发布前后对照、各步用时
- **发布包**:发布包目录里发现的包与校验结果;按起点版本预览升级计划(起点越旧步骤越多,来自各版本 release.yaml 的累计)。
- **资源配置**:发布包目录(镜像读取路径)、镜像仓库、Kubernetes、NAS、模型、中间件与白名单、统一认证、池子规模(容量估算)、发布策略。
  密钥只能更换、不能查看。
- **历史与回滚**、**操作记录**(不记录任何密钥的值)。

## 已拍板的设计决定(2026-11-02 / 03)

1. 白名单由白名单团队手工执行;发版台**只核对**:本版本应有的每条脚本是否都已登记、内容是否一致,没进去的逐条标出并可导出清单。
   核对数据源两种都支持:中间件脚本库只读账号(优先)/ 导入白名单团队给的导出文件(开不出只读账号时)。
2. 独立程序,不放进 k8s:拷贝容器镜像,一条命令起来;默认只绑 127.0.0.1。
3. 池子**在线发布**,不排空:release.yaml 声明新版本可与旧版本混跑时按槽位逐个替换
   (等不忙 → 转保留并写回 NAS → 腾挪 → 紧接着换这个容器的镜像 → 核验 → 空闲),每个 Pod 最后、所有槽位都不忙时换管家
   (换管家会把本 Pod 在用的人转保留,下一句自动恢复);不可混跑时自动改为按 Pod 整体替换。
   2026-11-03 已在测试环境实验确认,记录与据此定下的算法见 `docs/specs/2026-11-03-release-pool-swap-experiment.md`。
4. 开跑前扫描全部资源,齐全且可用才开始;外部依赖(NAS、模型、中间件、统一认证)只检查、不代为创建。首次部署也走这套流程(按建议先这样做)。
5. 第一版不做登录,只给封闭环境的运维用。
6. 代码在本仓库 `release/`,镜像 `gaussdb-agent-release`,同步到联合仓库。
7. 先做 P0 + P1;在 OrbStack 测试环境跑一次从零部署和一次升级,第一次真升级用 agent-v1.4.4。
8. 冒烟验证包含一次真实对话(客户模型本地部署,调用没有顾虑)。

## 演示与截图参数

打开后先「扫描资源」再「开始发布」;工具栏可调演示速度,可注入「资源扫描发现问题」「冒烟验证失败一次」。

URL 参数写在 `#` 后,用 `&` 连接:

| 参数 | 作用 |
|---|---|
| `page=` | 打开某页:overview / release / packages / config / history / audit |
| `scan=1` | 自动扫描资源 |
| `scanbad=1` | 扫描时 NAS 不可写 |
| `auto=1` | 自动跑完,放行所有关卡 |
| `stop=<步骤 id>` | 自动跑到这一步的关卡停下:review / whitelist / pool |
| `fail=1` | 冒烟验证失败一次 |
| `open=<0-11>` | 打开某一步的明细 |
| `speed=` | 演示速度 1 / 2 / 4 |
| `shot=1` | 关掉 CSS 过渡(无头截图时虚拟时间不推进过渡) |

截图:`"Google Chrome" --headless=new --virtual-time-budget=60000 --window-size=1480,1500 --screenshot=out.png 'file:///…/index.html#stop=pool&speed=4&shot=1'`
